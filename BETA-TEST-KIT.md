# Meraki Companion Beta Test Kit

**[Download the 0.4.60 Beta Test Kit (ZIP)](https://github.com/RotaryPumpers/Meraki-Companion-Preview/releases/download/v0.4.60-beta.1/RP-Meraki-Companion-0.4.60-Beta-Test-Kit.zip)**

The ZIP includes the Android APK and the Mac launcher for installing Secure Link, pairing your phone, rolling back, and removing the machine service. Extract it and open `START-HERE.md`.

This is an experimental prerelease for the documented US 110 V machine profile with MCU 5.1.4 and a compatible display build. Read the requirements and warnings before installing. Fresh installation and full removal with this exact kit still need live validation. [Prerelease notes and warnings](https://github.com/RotaryPumpers/Meraki-Companion-Preview/releases/tag/v0.4.60-beta.1)
